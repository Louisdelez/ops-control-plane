PÉRIMÈTRE
- Chine

- Europe : uniquement Mistral
- API/cloud uniquement
- Exclus : image, vidéo, audio/voix, 3D et modèles purement locaux

BASE DE COMPARAISON
Simulation mensuelle identique :
- 10 millions de tokens en entrée
- 2 millions de tokens en sortie
- USD, hors taxes
- coût = 10 × prix entrée par million + 2 × prix sortie par million
- prix standard temps réel, sans cache/batch sauf mention
- les prix peuvent varier selon région, longueur de contexte, cache, batch ou promotions.

NOTES
============================================================

- Ce fichier est un catalogue de routage/prix, pas un classement absolu d'intelligence.
- Les coûts simulés supposent exactement 10M tokens d'entrée + 2M tokens de sortie par mois.
- Cache, batch, promotions, région et longueur du contexte peuvent modifier fortement le coût réel.
- Pour Qwen, les prix changent selon la longueur de chaque requête ; le premier palier est utilisé quand indiqué.
- DeepSeek a une tarification heures creuses/heures pleines ; les deux coûts sont donc séparés.
- Les familles sans tarif API public unique sont volontairement marquées « variable » plutôt que d'inventer un prix.
- Certains chiffres évoqués oralement plus tôt dans la conversation étaient approximatifs ; les tarifs officiels vérifiables ont été privilégiés ici.
